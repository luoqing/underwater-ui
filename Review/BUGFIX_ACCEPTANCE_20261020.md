# 海底世界修复与验收

源快照：`baseline/layered-water-20261020`（`26ee34c`）。修复分支：
`fix/ui-missions-20261020`。原项目 `underwater-journey` 及 8878 服务由原 dev
继续维护，本分支使用独立项目缓存、构建目录和 8894 预览。

## 原因与改动

- 字体只有中文及少量符号，缺少 ASCII、数字、中点和图鉴圆圈。首轮 fallback
  在编辑器有效、WebGL 无效，实际截图复现后弃用。改为自带完整字符的单文件
  Blue Lantern UI，直接包含 30,923 个字符，不依赖浏览器或系统字体回退。
  原中文字体文件、28,601 个原映射的轮廓与字宽均保持不变；附生成工具及许可。
- 任务提示把两段文字硬塞进等高矩形，换行后截断。改为按真实文字高度排版，
  窗口变化同步字号；短屏菜单可滚动，任务框可收起。目标标记避让对白和任务框。
- 旧海床随镜头每跨 150 米搬动瓦片，各瓦片分别求法线；碰撞又使用不同于可见
  网格的连续曲面。改为固定 1.15 公里见方细节海床及约 9 公里远景，三角面
  采样与碰撞一致，共享连续法线。探索区域距细节网格边至少 176 米，外缘可后退。
- 去掉受阻后强制转镜头、侧移和未检测的脱困传送；改为实际碰撞滑动及初始
  重叠分离。真实拱桥保留非凸网格碰撞器，未用盒子封住开口。
- 场景实体挡住射线时停止选择；可见范围内优先识别救援绳结，避免龟的身体
  碰撞球抢走点击。任务切换清理此前选中的动物和移动状态。
- 修复龟/魔鬼鱼松手后强制回椭圆、丢失上浮方向、顶墙后停住；保留受限俯仰
  的最后可见方向，遇障碍用真实碰撞选择转向。
- 从原闭合网格重建损坏的近景珊瑚和鲸鱼；鲸鱼从逐段高度剪切改为连续中心线
  与弧长展开，重新蒙皮。鲸鱼自主前游与拖动互斥，推进节奏与尾骨同步。
- 首轮网页又发现出生点左侧 Reef 仍有大面积断面（与先修的 ReefShelf 不是
  同一模型），另行重建 Reef。源高模表面偏差采样的 95 分位改善约 72%，
  原材质和贴图字节保留；仍有少量极小退化缝，不宣称零缝或照片级效果。
- 救援目标统一为实际 48 米水面的近表面高度 47.7 米，相机可到 47.35 米；
  正常游动限制在 47.9 米以下。救援龟从水面下约 6 米开始，保持短关卡时长，
  避免从珊瑚区持续斜游约 140 米。任务可重玩，退出时清理对白。每步说明目的地、
  目标和操作。鱼线变细并半透明，球形绳结改为三股绳结构，保留金属笼信标。
- 网页试玩发现受困龟会在读对白时全速游出画面。缠绕期间改为小范围浮游和挣扎，
  鳍与游动组件保持启用；解开后恢复游动。水面标记显示海龟还需上浮的高度，
  不再把玩家镜头到标记的距离当成剩余救援距离。
- 按用户新要求，六向文字大按钮改为 44–48px 半透明箭头，按住高亮；左右两组
  分别移动和升降。任务提示缩为目的地和操作短句，计数与距离集中在目标标记。
  短屏对白避让实际方向控件矩形，去掉任务期间重复的中央标题。
- 继续点按发现标记仍会遮挡绳结或按钮，改为物体上方标签，并二次避让任务、
  对白、箭头及图鉴；任务框从 540px 预算收为 430px（仍随窗口缩放）。
  图鉴补入座头鲸，避免收录四种后出现 4/3；镜头松键后的减速从 2.1 提为
  12m/s²，减少贴近动物时继续滑过头，不改变动物释放后继续游动的规则。
- 修正焦散加光未受阴影遮挡；太阳灯使用单灯阴影偏移，避免既有 0.04 设置被
  管线默认值覆盖。水面需要的 opaque color 输入明确启用。保留 layered 水色、
  曝光、后处理和分辨率；增加的颜色拷贝成本尚需实机测量。

## 已通过的 Unity 校验

统一入口：`MissionGameplayValidation.RunAll`，需真实 Play Mode、不带 `-quit`，
脚本按检查结果退出。`Logs/bugfix-20261020/gameplay-final-validation.log` 退出码 0；
追加箭头、渲染输入和四种图鉴的重跑为 `gameplay-release-validation.log`，全部
校验标记通过，外层 Xvfb 退出显示 143，故不把后者包装成进程退出码 0。
早期这些日志按 6.2 米终点检查流程，只能证明当时的状态机和运动逻辑；鲸鱼侧面
复核时发现真实水面在 48 米，撤回“6.2 米已到真实水面”的判断。最终水面相关
验证以 `surface-validation-retry2.log` 为准，退出码 0，旧日志保留追溯。
其中一次编辑器启动卡在程序集初始加载，已终止本任务自己的进程；第一次重试
仍遇项目锁，待旧进程退出后再次运行成功，没有终止其他项目的 Unity。

- 10,449 个地形顶点/三角形/跨块法线采样；六向移动、墙前停止/后退、初始
  重叠、地面与探索边界校验通过。
- 龟持续直行 12 秒；从 2.7 米持续上浮到真实水面、近表面释放及限高；正面撞墙和边界后转向，
  全程未进入墙体；缠绕挣扎 20 秒保持非零小范围移动，解开后继续前游。
- 两条任务 × 四种角色，逐灯推进、顺序解三结、到水面完成、退出清理、再次
  救援，以及 14 个动物运动组件持续启用并活动。
- 实际导入的 `Natural Coral Reef Arch` 中央候选穿越路径：海龟 14/40、魔鬼鱼
  12/40、小丑鱼 14/40、鲸鱼 11/40 可通过。各处净空和适合体型不同，不代表
  每条路线都应放行。
- 中文、`W0123456789/`、中点和圆圈，在带图形设备的编辑器中均取得有效 glyph。
- 四角色 × 三盏灯共 12 条路线，以真实碰撞器每步 0.25 米从上一终点连续推进，
  全部到达 4.2 米完成圈。三盏灯中心未发现沙地/珊瑚实体覆盖；救援镜头到龟
  中心和首结射线均无遮挡。该检查不注入完成状态，但也不代表孩子能理解引导。
- HTTP 服务四项回归通过，包含压缩类型、条件请求、缓存和 404 行为。

这些流程测试通过正常任务方法和接近条件推进；测试会移动角色到目标附近。
它们不等同于儿童用鼠标/键盘完整游过每条路线，网页点击和画面仍需另行记录。

## 资产与职责边界

五份重建模型的材质 JSON 和所有嵌入图像 SHA-256 与快照一致。中文原字体字节、
小丑鱼行为、已认可的 layered 海水参数及其背景 shader 保持不变。
修复增加了部分近景几何预算；核显 1080p/60 帧尚未验证，不把编辑器测试当成
性能验收。珊瑚仍有少量极小退化缝，详见 `CREATURE_REPAIRS_20261020.md`。

按用户授权读取了 botmux `c14fbace-6529-401b-9feb-29e8d13237ca` 的开发记录。
dev 已将鲸鱼和字体交由本任务处理，仍负责蓝色鱼与小鱼群；本分支相应三类
运动代码与读取时 dev 源码一致，没有向该机器人发送消息或覆盖它的项目。

外部 `traex/openrouter-4o` 审查因模型 metadata 不可用而未能运行。已用独立
代理交叉审查，并修复其发现的短屏遮挡、目标标记遮挡、松手失去上升分量和
持续前游顶墙停住问题。

## 网页验收

第一轮实际 WebGL 已进场，使用隔离 Chromium（软件渲染），正常鼠标/键盘检查
了探险起步、六向操作、任务收起、救援角色选择和鲸鱼连续运动。截图记录在
`Logs/bugfix-20261020/browser/`。没有注入游戏状态或添加运行时作弊接口。

这轮实测发现字体 fallback 失效、左侧 Reef 仍破面、对白遮按钮、受困龟游出画面，
因此没有把第一版当成最终验收通过。后续构建及网页结果记录如下。

后续网页点按已确认完整数字/符号、小半透明箭头、海龟持续小范围浮游；正常鼠标
依次解开三处绳结并进入上浮阶段。证据：`browser-final/rescue-target-knot-click.png`、
`rescue-second-knot-click.png`、`rescue-all-knots-released.png`。没有注入完成状态。
鲸鱼网页观察显示完整尾鳍及持续运动，详查身体形态另有编辑器固定机位验证，
不把尾视截图冒充侧面近景验收。

最终预览：[修复版试玩](http://10.37.216.166:8894/?water=layered&v=bugfix-20261020-r5)。
运行时及资产提交：`42c3a64`；不覆盖原 8878。`webgl-surface-build.log` 构建成功，
进程退出码 0，总大小 133,475,406 字节。最终 `r5` 已实际打开并选择救援海龟，
检查近水面任务入场、中文/数字/箭头及提示布局。截图：
`browser-r5/final-rescue-856.png`，未捕获 JavaScript exception 或资源加载失败。
这不是“Unity 日志绝无警告”的声明：HTTP 下 Unity Cache API 与媒体设备提示
仍存在；内部未支持 shader 的日志也不能被 `errors: []` 自动排除。

编辑器自动改写的场景 ID、URP 版本标记已恢复至基线，清除本轮自动生成的
BillingMode 测试文件；没有改动原项目或删除用户游戏数据。

界面修复包构建：`webgl-accepted-build.log`，总大小 133,477,723 字节，Unity 构建成功且
进程退出码 0。该版 1440×900 / 856×408 网页截图已保存于 `browser-r4/`，字体、
紧凑箭头、任务框与标记位置可读；水面高度修正后的最终包为 `webgl-surface-build.log`。
为修复破面增加近景几何并补齐字体，不能把这版称作已减小加载包的性能版。

鲸鱼固定机位稳定态侧面复核见 `WHALE_VISUAL_RECHECK_20261020.md`：身体展开、
尾鳍连续，前后帧有实际前游和推进姿态变化。原始 0.58 秒帧有鲸和地面同时
出现色块，3 秒后预热及两帧未再复现；根因尚未严格区分，原坏帧保留。该采集
是编辑器 640×480、URL 为空的检查，不冒充网页 layered 水色或照片级验收。

软件渲染不是用户核显实机，不能用其帧率判断 1080p/60 帧。完整手动双剧情通关
与四角色全路线仍需区分于编辑器自动流程测试，不冒充已经逐条手动验收。
